# CommandPalette

`CommandPalette` 根据查询筛选命令，禁用的命令不进入可执行结果。键盘移动、最近记录和激活都使用**当前可见的结果集合**：查询把列表缩小后，方向键只在剩余项之间移动，Return 只运行列表里高亮的那一条，不会落到被查询隐藏的命令上。

`PaletteCommand::enabled(false)` 禁止该命令显示和执行；菜单中保留禁用项的语义由 `Menu` 单独提供。

## 几何

桌面宽度下固定 640pt、距窗口顶部 72pt，内容高度受窗口剩余空间限制。窗口窄于 600pt 时改用居中的紧凑几何：左右内缩 8pt，高度取窗口高度减 16pt（上限 560pt），不再使用顶部偏移。

## 焦点

搜索框是唯一的 Tab 停靠点；结果行只响应指针与方向键，Tab 不会逐行走过整份结果列表。这与 Swift 的 `CommandResultModifier` 一致。

共享 Rust 实现覆盖所有宿主平台。自动化场景验证与原生视觉、键盘及 IME 验收分别记录在 Gallery 验收表中。
