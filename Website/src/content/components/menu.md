# Menu / MenuItemContent

`MenuItemContent::new` 的样式标题保留字体与颜色，但移除片段中的链接，整行是唯一激活目标。`MenuItem::title` 继续用于辅助功能名称和键入搜索。

行级 `link` 可标识目的地址，激活仍执行该项 action。

共享 Rust 实现覆盖所有宿主平台。自动化场景验证与原生视觉、键盘及 IME 验收分别记录在 Gallery 验收表中。

## 行密度与分节

单行行高取 label 行高加上下各 3pt 留白（默认字号 24pt），且不短于 20pt 下限；触屏表面按 44pt 抬高。`minimum_row_height()` 这一 CompositionLocal 可以把整份菜单改高（例如 44pt 的选择器），行自身与面板按同一度量结算，`max_visible_rows` 限制的是真正可见的行数。

勾选列与图标列各 12pt、列间距 6pt，是否出现由整级条目共同决定，所以全部标题落在同一列。`MenuEntry::label` 不是行，它借用同一套列宽让分节标题对齐标题列。`MenuEntry::separator` 是 1pt 细线加上下各 5pt 空隙，空隙在细线之外——留白写在细线节点上会让背景把分隔线画成色带。

## 动效

面板进入用主题的 surface 时长（0.2s）与 0.94 缩放，锚点在触发器一角；关闭走更短的 0.09s，不复用进入曲线。减弱动效时两者都直接呈现。悬停与键盘高亮即时切换，不做淡入淡出。菜单行不改指针形状：可激活项与禁用项都保持箭头。
