# HoverCard

`HoverCard::new(label, content)` 在指针停留达到 `open_delay` 后显示内容；离开入口到进入卡片之间由 `close_delay` 保留。

整个卡片都是悬停面，不只是卡片里的控件：指针从入口移到卡片任意留白都保持打开，移出后按关闭延时收起。

卡片中的控件属于入口的焦点作用域；Escape 关闭卡片并保留原焦点。指针按下卡片外部或按下入口同样关闭。

卡片默认宽 300pt（`width(Some(...))` 可改），放在入口下方，窗口底部放不下时翻到上方。

触摸环境使用同一内容的 sheet：入口是一个按钮，点击后从底部展开。

Gallery 的示例同时提供指针悬停卡与键盘可达的 Popover 入口，两者共用同一份内容与动作。

共享 Rust 实现覆盖所有宿主平台。自动化场景验证与原生视觉、键盘及 IME 验收分别记录在 Gallery 验收表中。
