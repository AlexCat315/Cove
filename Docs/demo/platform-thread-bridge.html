3 · 54 个调用的归属

只有 B 类真的需要排队；C 类全部靠缓存消除往返，这是能去掉同步语义的关键。

类别方法机制阻塞 UI？
A 合并set_cursor · set_text_input_area · set_window_chrome_hit_test · set_window_size/position · keep_rendering按 (窗口, 种类) 覆盖槽位否
B 排队show_window_system_menu · NativeMenuPopover::pop_up · clipboard write · open_*_dialog · create/close_window · shutdown严格 FIFO，结果回投事件否
C 缓存drawable_size · logical_size · content_scale_factor · is_focused/minimized/occluded · safe_area · refresh_rate · clipboard read(异步)主线程 publish 快照否
阻塞原语dispatch_sync 到主线程本设计不提供会
